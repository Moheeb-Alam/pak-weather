# Mausam — Pakistan Weather App

HTML + CSS + Tailwind (CDN) + Node.js (Express) + Open-Meteo API (free, no API key).

## Run locally
1. Install Node.js 18+ from https://nodejs.org
2. `npm install`
3. `npm start`
4. Open http://localhost:3000

## Deploy
Push to GitHub, then import the repo in Vercel (no build settings needed).
The `api/` folder becomes serverless functions and `public/` is served as the website.
